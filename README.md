## Selected work

**Trust-Aware Federated Learning** *(IEEE COMPSAC 2026)* — A client-scoring framework using contrastive attention and representation clustering to defend federated training against malicious or low-quality participants.

**HVAC Digital Twin with MPC Control** — Real-time digital twin of an HVAC system with model predictive control for energy-efficient operation.

**Baltic Sea Coastal Ecosystem Twin** — Real-time digital twin built on Eclipse Ditto, integrating sensor streams for ecological monitoring (TalTech).

**Adversarial ML on Autonomous Driving** — Targeted backdoor data poisoning of traffic sign detection in CARLA, exploring vulnerabilities of CNN-based perception.

**Medical Imaging** — 3D orientation augmentation for breast cancer detection on NIfTI volumes; lung-disease classification on ChestMNIST; 3D object classification on ModelNet10/40.

**Retrieval-Augmented Systems** — RAG pipeline for financial QA on Bitcoin news; RAG analytics for industrial oven usage at the Unox AI hackathon (AWS).
